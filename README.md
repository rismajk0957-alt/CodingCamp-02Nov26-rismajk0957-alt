
# To-Do List Life Dashboard

## Deskripsi
To-Do List Life Dashboard merupakan aplikasi website sederhana yang membantu pengguna mengatur aktivitas sehari-hari, mengelola daftar tugas, dan meningkatkan produktivitas.

Website ini dibuat menggunakan HTML, CSS, dan JavaScript dengan penyimpanan data menggunakan Local Storage.

## Fitur Utama

1. Digital Clock: Menampilkan waktu dan tanggal secara otomatis.
2. Greeting: Menampilkan sapaan berdasarkan waktu.
3. Focus Timer: Timer fokus selama 25 menit.
4. To-Do List: Menambahkan, mengedit, menyelesaikan, dan menghapus tugas.
5. Quick Links: Menyimpan tautan website favorit.
6. Local Storage: Menyimpan data agar tidak hilang ketika halaman dimuat ulang.

## Fitur Tantangan

1. Dark Mode: Mengubah tampilan website menjadi mode gelap.
2. Custom Name Greeting: Menampilkan sapaan menggunakan nama pengguna.
3. Prevent Duplicate Tasks: Mencegah penambahan tugas yang sama.

## Teknologi

- HTML
- CSS
- JavaScript
- Local Storage
- Kiro IDE
